# MacSweep

Cleanup, storage inspection and security checks for your Mac, by Engaze.

**Website:** https://macsweep.prerakgada.in

## Download

The first release is **0.1.0 alpha**, for Apple Silicon Macs running macOS 26 or newer.

[Download MacSweep 0.1.0](https://github.com/PrerakGada/macsweep-releases/releases/download/v0.1.0/MacSweep-0.1.0.dmg)

Open the disk image and drag MacSweep to Applications. The app and disk image are Developer ID signed and notarized by Apple.

```sh
brew install --cask prerakgada/tap/macsweep
```

Read the release notes before using this early alpha. Cleanup and administrator actions change real files after you confirm them. Review the selected items and keep current backups. MacSweep is not an antivirus or a guarantee that a Mac is safe.

Scan results stay on your Mac. The app goes online for feedback you choose to send and for optional update checks. Report a Problem and Send Feedback are available in the menu bar, Help menu and Settings/About.
